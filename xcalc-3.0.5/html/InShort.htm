xcalc in short

xcalc is a highly configurable, “extended” calculator for 32-bit Linux, MacOSX and Windows that you can use for simple calculations using decimal or complex floating point, or hexadecimal, octal or binary integer numbers (64, 32, 16 and 8 bit signed 2's complement). The program uses RPN (Reverse Polish Notation), similar to the classic Hewlett-Packard handhelds.

The user interface is designed for ease of use, and you can use the keyboard or mouse for all operations as you please. To find 123+456, for example, key in “123 <Enter> 456 +”. The weakness with using the keyboard is of course the lack of square root keys and such on the PC, but the keyboard interface is definitely faster than the mouse. If you can't remember the keys for the various mathematical operations, the tooltips can remind you, or press Ctrl-F1 to get instant keyboard help. You will also find memory store/recall functions, interaction with the clipboard (coming!), setting of various modes such as Decimal/Complex/Hex/Octal/Binary, and “Fix” or “Float” decimal settings. Fractions and degree-minute-second numbers are also supported.

xcalc will remember its settings and content between sessions; in the file xcalc.ini is kept the various configurable items, (not yet the stack and memory registers or screen position).

Memory registers

XCALC is equipped with ten memory registers; each can hold one number in Decimal, Fraction, Complex or Integer (Hex/Oct/Bin) format. The keys to control the memory are as follows:

  • Ctrl-n Store the X register in memory cell n (0≤n≤9).
  • Ctrl-Shift-n Recall memory cell n to the X register.
  • Ctrl-Alt-n Clear (zero) memory cell n.
  • Ctrl-Alt-m Clear all memory registers

As a reminder, XCALC will show small digits to the left of the screen that represent the memory registers. If a register contains zero, the digit is shown in white, otherwise in red.

There is no saving of memory content between sessions.

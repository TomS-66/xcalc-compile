Mouse interface

I don't encourage operating a calculator with a mouse. Nevertheless, due to countless requests the XCALC display is chock-a-bloc full of mouse-friendly buttons. Apart from clicking on all those function keys, you can also do the following operations with the mouse in XCALC:

  • Click on Config, Help and Exit
  • Rotate the stack using the wheel (if present)

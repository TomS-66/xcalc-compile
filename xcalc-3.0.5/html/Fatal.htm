A maths exception has occurred in XCALC

Oh dear..!

This error happens if you generate an overflow or a singularity that is not trapped by the XCALC emergency routine. The author thought that such an error should not occur, but it just did. Please and report what happened.

Your only option now is to click “OK”, and the XCALC instance will be closed. Note that the program will not exit in a normal manner, but all the settings (such as mode, position etc.) will be updated as usual. However, floating point operations are prohibited at this point, so your registers will not be saved. Hopefully your operating system will clean up any orphaned resources!

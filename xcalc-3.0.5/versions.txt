pXcalc versions, 3.0+:

3.0.1, 2011.10.18: based on XCALC 2.9.4 but completely rewritten in C++
3.0.2, 2012.02.06: Help implemented via html dubdirectory. Everything can be undone/redone. Better keyboard layout.
3.0.3, 2012.02.19: Several small fixes: BACK works. No support for fractions in complex mode.

        Root extraction (integer roots) better.
        No more sigaction - signals never worked, and results are inf/nan as appropriate instead.

        Fixed: ROUND also misses strings like "1 1/2"
        Fixed: undo/redo when ROUND is involved.
        Added mouse wheel handler to scroll stack 14apr12
        Rudimentary memory registers implemented, with indicator showing value
        Abs works, dflt conversion to binary is real value only.
        Fixes wrt word sizes, shift etc.
        Fixed: problems with wordlength/signedness/float conversion...
        Round now works better on input - removes frac and DMS as proposed.
        Added explicit copy constructor and assignment operator for Register/Inttype. Seems to work OK.

        Added proper handling of fractions as Inkey!
        Help pages updated.
